# Jiabaoyi Wang — Academic Homepage

Personal academic homepage of **Jiabaoyi Wang (王嘉宝仪)**, Ph.D. student at Zhejiang University, Ubiquitous System Security Lab (USSLAB).

**Website:** [https://jiabaoyiwang.github.io](https://jiabaoyiwang.github.io)

Research areas include embodied AI security, adversarial evaluation of robotic foundation models, trustworthy world-action modeling, and safety alignment of vision-language-action models.

## Editing this website

This site uses [Jekyll](https://jekyllrb.com/) and GitHub Pages.

- **Homepage content:** edit `_pages/about.md`.
- **Name, profile photo, sidebar and social links:** edit `_config.yml`.
- **Navigation links:** edit `_data/navigation.yml`.
- **Local preview:** with Ruby and Bundler installed, run `bundle install` and `bundle exec jekyll serve`, then open `http://127.0.0.1:4000`.
- **Publication entries:** add verified papers to `_pages/about.md`. The starter template's example paper and sample citation counts have been removed.
- **Google Scholar:** optional; the citation workflow is manual-only until your own Google Scholar ID is configured. To use it, add the repository Actions secret `GOOGLE_SCHOLAR_ID` and run the workflow manually. Do not use another scholar profile.

To publish with GitHub Pages, select `Settings → Pages → Build and deployment → Deploy from a branch → main / (root)`.

Push changes to `main` to update your deployed site.
